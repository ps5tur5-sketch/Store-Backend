# Изменения второго этапа

Первый этап сохранён в коммите `259ec14`. Новые коммиты продолжают эту историю; миграции 001–005 и исходные каталоги не заменены. Это список изменений относительно первого этапа, а не только перечень файлов.

| Область | Было | Стало |
| --- | --- | --- |
| Заказ | Одна позиция `orders` | `order_groups` объединяет несколько прежних позиций; фиксируются продавец, цена и партия |
| Частичный сбой | Обработка отдельного товара | Независимое завершение позиций, частичный возврат, общий денежный итог |
| Ненадёжный поставщик | Timeout и повтор | Дубли/чужие коды/ошибка после выдачи, независимая проверка, resolve и подтверждённая отмена |
| Перезапуск | Базовые попытки выдачи | Устойчивая очередь, аренды, защита от старого worker, восстановление после SIGKILL |
| Ограничение поставщика | Без общего бюджета | Скользящий бюджет 60 секунд в PostgreSQL для всех worker, перенос задания без потери |
| История и деньги | Текущее состояние и базовый журнал | Добавляемые снимки, точный COMMIT новых операций, история на дату и итоги периода |
| Продавцы | A/B | Расширяемые магазины, разные предложения одного товара, независимые остатки |
| Доступ | Покупательский аккаунт | Единая покупка/продажа, подключение магазина, разграничение прав на сервере |
| Репутация | Нет | Отзывы 1–5 по завершённой покупке, подтверждённые нарушения и красный флаг |
| Оплата | Баланс и тестовый код | Сохраняемые СБП/USDT, повторы/отмена/истечение, пополнение и возврат в wallet |
| Вывод | Нет | Заявка на карту/USDT, резерв, тестовый успех/отказ, денежная сверка |
| Модерация | Базовая админка | Бан/разбан, отзыв ключа и возврат, приватный чат, закрытие чата после возврата |
| Финансы продавца | Нет отдельного отчёта | Цена покупки, закупка, возвраты, доход и прибыль по всем страницам |
| Склад | Цена предложения на SKU/продавца | Партии 200/400/400 и прямая цена каждого ключа; резерв точного товара |
| Проверки | Исходные сценарии одиночного заказа | 71 интеграционный тест на отдельной PostgreSQL, воспроизводимый сценарий сдачи |
| Поставка | Исходный Docker Compose | Та же схема запуска, миграции 006–015, шаблон окружения, CI и документы сдачи |

Совместимость: одиночный `POST /api/orders {sku}` сохраняет форму и fallback A → B. Новые контрактные поля дополняют API. Старые выданные ключи, продажи и история не перезаписываются; для исторических операций без точного COMMIT явно указано `legacy_reconstructed`.
