# Проверки серверной части

8 сентября 2026: **71 / 71** интеграционных тестов прошли на PostgreSQL 17 в изолированном Docker profile. [Полный вывод](verification/backend-tests.txt). TypeScript проверяется в Docker build до запуска тестов. [GitHub Actions](https://github.com/ps5tur5-sketch/Store-Backend/actions) воспроизводит сборку и тесты на каждом push/PR.

| Требование / риск | Проверка в `tests/acceptance.test.ts` |
| --- | --- |
| Дублирующий webhook | 50 параллельных оплаченных событий и повтор: одна выдача |
| Частичный сбой | 2389 = 1990 + 399, повтор оплаты/recovery сохраняет деньги |
| Ненадёжный поставщик | Параметризованные duplicate/wrong/error-after/timeout-after |
| Авария процесса | Настоящий SIGKILL после COMMIT поставщика, восстановление единственной выдачи |
| Старый worker | Просроченная аренда не позволяет второй фиксации |
| Лимит и приоритет | Бюджет/попытки сохраняются между проходами, recovery не сбрасывает отсрочку |
| Денежная целостность | Несбалансированная проводка отклоняется на COMMIT |
| История | Создание/оплата/частичная выдача и общая COMMIT-граница группы, пропущенный архив |
| Права | Чужие заказы/ключи/чаты недоступны, бан отзывает сессии, разбан восстанавливает вход |
| Репутация | Одна оценка 1–5 по своей завершённой покупке; доказательства без секретного кода |
| СБП/USDT и wallet | Подтверждение/повтор/отмена/истечение, пополнение и возврат ровно один раз |
| Вывод | Резерв/завершение/освобождение, параллельные заявки без перерасхода |
| Финансы продавца | Исходная цена/закупка, возврат, неизвестная себестоимость, итоги всех страниц |
| Партии | 1000 ключей → 200/400/400, повтор без дублирования, точный резерв и выдача |
| Индивидуальная цена | Два ключа → 1/2 ₽, точная покупка за 3 ₽, повтор PUT, конкурентный checkout |

[Сценарий частичного сбоя](verification/stage2-scenario.txt) · [Сверка рабочей БД](verification/runtime-verification.json) · [Партии после перезапуска](verification/lot-verification.json).

Проверки не заменяют стресс-тест на заранее оговорённой производственной нагрузке. Тесты воспроизводят конкуренцию и нарушение инвариантов; реальный банк, блокчейн и активация на игровых платформах не подключаются по условиям задания.
